# Nahual Auto: First Drive

Nahual Auto — Prototipo Web Inicial

Quiero crear el primer prototipo de un sitio web profesional para Nahual Auto, una marca salvadoreña de productos para cuidado, limpieza y detailing automotriz.

He adjuntado varias capturas de las redes sociales actuales de Nahual Auto. Utilízalas como referencia visual de la identidad de la marca, especialmente para colores, estilo gráfico, fotografía de producto, composición, iconografía y personalidad visual.

Objetivo de esta primera versión

Crear una página web moderna, profesional y visualmente atractiva que presente la marca y sus productos.

Por ahora NO necesito implementar pagos, carrito, autenticación, base de datos ni integración con Shopify. Esta primera etapa es exclusivamente para validar el concepto visual, estructura y experiencia de usuario.

La página debe sentirse como una marca real de productos automotrices, no como una plantilla genérica.

Identidad de marca

La personalidad de Nahual Auto debe transmitir:

Profesionalismo

Modernidad

Tecnología

Potencia

Limpieza

Detailing profesional

Calidad

Una sensación ligeramente premium

Identidad salvadoreña

El estilo visual debe inspirarse en las publicaciones proporcionadas, pero NO copiar literalmente los diseños de Instagram.

Quiero transformar esa identidad en una experiencia web propia, limpia y moderna.

Paleta de colores

Utiliza principalmente esta paleta:

Primary Orange: #D2540F

Dark Orange: #A7380B

Navy: #1B1E27

Dark Navy: #0C0F15

Light Orange: #F8A782

Light Background: #F5F3F2

White: #FFFFFF

Dark Text: #171522

Regla de uso

No quiero una página completamente naranja.

Utiliza aproximadamente:

60% blancos y tonos claros

25% navy/dark

10% naranja

5% accent/light orange

El naranja debe utilizarse principalmente para:

CTAs

botones

elementos destacados

pequeños detalles visuales

indicadores

elementos interactivos

El navy debe ser importante para crear contraste y una identidad automotriz fuerte.

Tipografía

Utiliza:

Headings

Poppins

Bold para H1

SemiBold para H2/H3

Body/UI

Inter

Regular para textos

Medium/SemiBold para botones y elementos importantes

La tipografía debe sentirse moderna, geométrica y limpia.

Elementos visuales

La identidad de Nahual Auto utiliza un símbolo/logo geométrico.

Utiliza el logo y las imágenes proporcionadas como referencia.

También quiero incorporar sutilmente el patrón gráfico asociado al logo como elemento decorativo.

IMPORTANTE:

El patrón debe utilizarse con muy baja opacidad, aproximadamente 5–8%, para que sea un detalle de marca y no distraiga.

Puede aparecer en:

fondos de algunas secciones

separadores

cards

footer

áreas decorativas

No utilizarlo en todas las secciones.

Automotive + Detailing + Modern Brand + Premium + Salvadoran

exceso de sombras

exceso de naranja
